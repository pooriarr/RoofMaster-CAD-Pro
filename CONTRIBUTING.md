# Contributing to RoofMaster Pro

Thank you for your interest in contributing to **RoofMaster Pro**! We welcome community contributions, bug reports, and feature requests.

---

## 🛠️ Development Workflow

1. **Fork & Clone**: Fork the repository to your account and clone it locally.
2. **Branch**: Create a descriptive branch for your feature or fix:
   ```bash
   git checkout -b feature/my-new-feature
   ```
3. **Install Dependencies**:
   ```bash
   npm install
   ```
4. **Develop & Verify**:
   - Run the local dev server: `npm run dev`
   - Run the linter: `npm run lint`
   - Verify the production build: `npm run build`
5. **Commit**: Follow conventional commit guidelines:
   ```bash
   git commit -m "feat: add support for trapezoidal rib pitch calculation"
   ```
6. **Push & Pull Request**: Push your branch and open a PR against the `main` branch.

---

## 🐞 Reporting Issues

If you discover a bug or have a suggestion:
- Check existing issues to prevent duplicates.
- Provide step-by-step reproduction steps, expected vs. actual behavior, and system environment info (OS, Node version).
